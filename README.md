# Project: Vehicle Detection with YOLOv8 and Transfer Learning

This project demonstrates the process of training a YOLOv8 object detection model using **transfer learning** on a custom vehicle dataset. The goal is to create a model capable of identifying and localizing different types of vehicles in images.

---

### Technologies Used

* **Google Colab:** A cloud-based development environment with GPU access.
* **YOLOv8:** A state-of-the-art object detection model by Ultralytics.
* **PyTorch:** The machine learning framework used by YOLOv8.
* **Roboflow:** The platform used to obtain and prepare the dataset.
